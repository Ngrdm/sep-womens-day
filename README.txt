SEP Women's Day Greeting Card - Vercel deployment

This is a static HTML project. No build command, framework, or dependencies are required.

Deploy with Vercel:
1. Extract this ZIP.
2. Import the extracted project folder into a GitHub repository, or use the Vercel CLI.
3. In Vercel, select the project and set Framework Preset to Other.
4. Leave Build Command empty and Output Directory as public.
5. Deploy.

The original HTML design and embedded assets are preserved in public/index.html.
